# Интеграция PlanktonAI в шахматную страницу

## Запуск
Откройте сайт через GitHub Pages по адресу `/ai/chess/`. Модель запускается в браузере через ONNX Runtime Web (WASM); Python-сервер не требуется. Первый запуск скачивает ONNX Runtime и файлы модели.

## Формат входа
Адаптер повторяет фактическую реализацию `core/data.py`:
- доска: 8×8, FEN от 8-й горизонтали к 1-й; пустая клетка = 0, белые фигуры = 1–6, чёрные = 7–12;
- контекст: `[white_to_move, black_to_move, K, Q, k, q, halfmove_clock / 50]`;
- четыре головы модели: `from_x, from_y, to_x, to_y`; выбирается легальный ход с максимальным произведением соответствующих вероятностей.

Внимание: описание Context в README исходного PlanktonAI не совпадает с `core/data.py`. Для совместимости использован именно код подготовки обучающих данных. В частности, en passant не входит в обучающий контекст.

## Ограничения проверки
Ветка подготовлена через GitHub API. Полноценный прогон ONNX-модели в реальном браузере и проверка GitHub Pages требуют отдельного запуска после публикации. Если текущая сборка ONNX Runtime не поддерживает opset модели или внешний файл весов, модель сообщит об ошибке загрузки в статусе страницы; в таком случае нужно переэкспортировать модель под поддерживаемый opset и повторить тест.
